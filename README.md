# Iber-LagoHealth

Web bilingüe del proyecto Iber-LagoHealth (`PID2023-151954NB-I00`), preparada para GitHub Pages.

## Publicar la web

Las instrucciones completas están en [EDITAR_WEB.md](EDITAR_WEB.md).

Resumen:

1. Crear en GitHub un repositorio público llamado `iberlagohealth`.
2. Subir a la raíz del repositorio **el contenido de esta carpeta**, no el archivo ZIP.
3. En `Settings > Pages`, seleccionar `Deploy from a branch`, rama `main` y carpeta `/(root)`.
4. La dirección será `https://TU-USUARIO.github.io/iberlagohealth/`.

## Archivos que se editan habitualmente

- `js/data.js`: noticias, publicaciones, congresos y vídeos de los objetivos.
- `js/team.js`: miembros, perfiles, enlaces y fotografías.
- `assets/team`: fotografías del equipo.
- `assets/videos`: vídeos y portadas.
- `assets/gallery`: fotografías de la galería.

No es necesario modificar los archivos CSS para actualizar contenidos.
